## About

KidLock helps families manage screen time on Android TV devices and compatible TV boxes. It provides a PIN-protected administration area, daily limits, scheduled time windows, and a lock screen designed for remote-control navigation.

The project is open source under the GNU Affero General Public License v3.0. Contributions, bug reports, and testing feedback are welcome.

## Features

- Daily screen-time limits.
- Recurring schedule windows with block and allow modes.
- Reliable global blocking during an active blocking window.
- Six-digit administrator PIN protection.
- Temporary access codes generated by the parent.
- Recovery of the monitoring service after device restart.
- Guided first-run setup for Android permissions.
- D-pad and remote-control navigation.
- Responsive layouts for phones, Android TV boxes, 1080p, and 4K screens.

## Compatibility

- Android 7.0 or later (API 24+).
- Android TV and Google TV devices with Accessibility Service support.
- Compatible Android TV boxes, subject to the permissions and restrictions of each firmware.

Blocking reliability depends on the permissions granted, the device manufacturer, and the Android TV version. A regular application cannot provide the same guarantees as a device configured as Device Owner or kiosk.

## Permissions

KidLock requests only permissions required for its core functions:

- **Accessibility Service**: detects the foreground window and returns to the lock screen when a rule is active.
- **Usage access**: measures application usage for daily limits.
- **Display over other apps**: helps bring the lock screen back to the foreground.
- **Run after boot**: resumes monitoring after the TV restarts.
- **Device administration, when enabled**: provides the device-admin protections supported by Android.

The setup flow explains these permissions before they are enabled. Disabling a required permission can prevent blocking from working correctly.

## Build from source

```bash
git clone https://github.com/yanmasharski/kidlock-tv.git
cd kidlock-tv
./gradlew testDebugUnitTest
./gradlew assembleDebug assembleRelease
```

The generated APKs are located under `app/build/outputs/apk/`. To install on an Android TV box, transfer the release APK to the device and allow installation from the selected source.

## Architecture

- Kotlin and AndroidX.
- MVVM-inspired separation between activities, ViewModels, data storage, and services.
- `MainActivity`: lock screen and access-code entry.
- `AdminActivity`: PIN-protected administration.
- `ScreenTimeAccessibilityService`: foreground-window monitoring and lock-screen enforcement.
- `ScheduleManager`: schedule resolution.
- `DataRepository`: local settings and usage persistence.

## Privacy and security

KidLock is designed to process settings, PIN data, schedules, counters, and access codes locally on the device. This version does not require a cloud account and does not include remote advertising analytics.

Do not publish PINs, access codes, device identifiers, or private logs in issues or pull requests. See the repository security guidance before reporting a vulnerability.
